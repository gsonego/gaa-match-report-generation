# GAA Match Report Generation

MSc in Applied Data Science dissertation — Dundalk Institute of Technology (2026–2027).

**Topic:** Applying large language models to the writing of GAA match reports, with a focus on factual accuracy.

## Structure

| Folder | Content |
|---|---|
| `src/` | Source code |
| `data/` | Data description and processed datasets (no raw third-party data) |
| `prompts/` | Experiment prompts, versioned |
| `results/` | Final results |
| `journal/` | Weekly project journal |
| `docs/` | Supporting documents, including the AI usage log |
